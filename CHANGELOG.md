# Changelog

All notable changes to FARMAN Terminal are documented here.

## 0.3.0

### Added

- Command palette (`Ctrl+K`) with multi-term filtering, keyboard navigation,
  theme switching, bidi toggle, shell selection and config reload.
- Title-bar command search field.
- Trilingual Windows installer: English, Persian and Arabic, including RTL
  wizard layout.
- Open-source project files: contributing guide, code of conduct, security
  policy, issue/PR templates and GitHub Actions CI/release workflows.

### Changed

- Reworked the title bar and overlay styling for a cleaner, more focused
  glass look.
- Updated release packaging and documentation for the 0.3.0 release.

## 0.2.0

### Added

- Custom frameless Windows chrome, tabs, profile menu and settings sheet.
- Per-user Inno Setup installer, portable ZIP and per-user install script.
- New FARMAN emblem and refreshed application icon.
- Embedded Pinar UI typography with Persian/Arabic shaping support.

## 0.1.0

- Initial GPU-rendered ConPTY terminal with Persian/Arabic bidi support.
